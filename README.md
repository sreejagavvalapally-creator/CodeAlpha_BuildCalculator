# Build Calculator

A simple and user-friendly calculator application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear/reset functionality
* Simple and responsive user interface
* Displays the entered values and calculated result
* Handles basic invalid calculations such as division by zero

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
Build-Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Use the calculator buttons to perform calculations.

## How It Works

The calculator accepts numbers and arithmetic operators through the user interface. JavaScript handles the button clicks, performs the selected mathematical operation, and displays the result on the screen.

## Example

```text
10 + 5 = 15
20 - 8 = 12
6 × 4 = 24
20 ÷ 5 = 4
```
