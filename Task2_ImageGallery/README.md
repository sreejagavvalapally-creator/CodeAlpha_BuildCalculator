# 🖼️ Image Gallery

A responsive and interactive **Image Gallery** built using **HTML, CSS, and JavaScript** as part of my **CodeAlpha Frontend Development Internship**.

## 🚀 Features

* 📸 Responsive image gallery layout
* 🔍 Full-screen image preview using lightbox
* ⬅️ Previous and Next image navigation
* ✨ Smooth hover effects and transitions
* 🏷️ Image category filters
* 📱 Fully responsive design for mobile, tablet, and desktop
* 🎨 Clean and modern user interface
* ♿ Alt text for images and keyboard-friendly controls

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling, responsive layout, animations, and transitions
* **JavaScript** – Image filtering, lightbox, and navigation functionality

## 📸 How It Works

1. Browse the images displayed in the gallery.
2. Use the category buttons to filter images.
3. Click any image to open the lightbox.
4. Use the **Previous** and **Next** buttons to navigate.
5. Click the **Close** button to return to the gallery.
